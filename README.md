# CHAIN//REACTOR

壊す。戻す。違う一手を試す。

[ブラウザで遊ぶ](https://jounouchi666.github.io/CHAIN-REACTOR/) · [遊び方・取扱説明書](MANUAL.md) · [GitHub Pages公開手順](DEPLOY.md) · [検証結果](EVALUATION.md)

剛体・破断・熱・爆発・電気・磁場・重力井戸・水と蒸気が同じ実験槽で干渉する、ローカルの連鎖実験室。巻戻し後には上書き前の実測運動を重ねられる。映像を再生しているだけのデモではない。

## 起動

検証環境: Windows / Node **22.15.0** / npm **11.4.1** / Playwright Chromium。ブラウザはChromium系を対象としている。Firefox・Safari・実機スマートフォンでの検証はしていない。

```powershell
npm ci
npm run build
npm start
```

ブラウザで <http://127.0.0.1:4191/> を開く。サーバーはループバックにだけbindし、外部へ公開しない。4191番が別用途で使われている場合、そのプロセスを自動終了しない。

通常の実行に外部API・アカウント・認証・課金は不要。初回の依存インストールにはnpmレジストリへの読取アクセスが必要。依存はlockfileで固定。

## 最初の30秒

「通電」で塔群を解体。次に「3秒戻す」で停止し、別の場所へ射撃して再開。「前回を重ねる」の点線は前回の剛体の動きであり、想像で生成した予測ではない。

6場は、塔群の解体、割った槽からの冷却、折返し導火線、鋼球の機械接点、落下から次段への点火、短い通電で止める重力炉。「自由制作」から空の槽にもできる。

## 操作

| 操作 | 入力 |
| --- | --- |
| 照準・射撃 | マウスで狙ってクリック／タッチして離す／矢印とSpace |
| 選択中の制作道具 | クリック／Enter |
| 移動 | 掴んでドラッグ／Enterで掴み、矢印、Enterで放す |
| 回転・固定切替 | 狙った部品に `[` / `]`、`F`／回転・固定ボタン |
| 配線・接合 | 2部品を順番に選ぶ |
| 通電・再実験 | `E` / `R` |
| 拡大・移動 | ホイール／2本指／拡大縮小ボタン／視点道具／Shiftと矢印（初期位置は「視点を戻す」） |

画面内の「操作ガイド」に詳細と限界を記載。ガイド中は時間が止まり、閉じると元の状態へ戻る。音は明示的に開くまで無音。

下部のスピーカーボタンでSEをON/OFF。爆発・衝突・ガラス・砲撃に加え、通電・配置・配線・水・巻戻しをWeb Audioで合成する。音量は設定内。外部音源やBGMは使わない。SEボタンは狭幅でもメニューに隠さない。

狭幅・低い画面では保存、音量、動き軽減、視点操作を下部の「設計と設定」にまとめる。通常は画面内に操作を固定し、実験槽を残りの高さへ合わせる。高さ540px未満では操作性を保つためページスクロールを許可する。

## 静的配布・アイコン

`npm run build:pages` でGitHub Pages用 `_site/` を生成し、`npm run preview:pages` でサブディレクトリ配置を確認できる。`npm run build` はアプリのbundleに加え、SVG原稿からfavicon／180px Apple Touch Icon／192・512px manifest iconsと、`MANUAL.md` からブラウザ用 `manual.html` を生成する。取説は操作ガイドから別タブで開ける。

`.github/workflows/pages.yml` は手動公開用。pushだけでは公開しない。Safari/iOSの実機確認は未実施。オフライン起動は未対応。

## 検証

```powershell
npx playwright install chromium
npm run verify
npm run measure
```

`verify` はNodeの自動テスト、bundle、実ブラウザE2E。E2Eは接続先が本アプリと識別できない場合に操作を拒否する。画像・動画・音響WAV・性能JSONは `test-results/`、比較・ベンチマークの出力は `evidence/`。生成物はGit対象外。

## 意図的な限界

- 工学解析器ではない。剛体はMatter.js、液体は質量保存cellular近似。熱・浮力・場・破断は遊ぶためのモデル。
- 制作600／全体800部品、配線・接合は各1200本、水70000セル、演出420粒子、音18voiceの上限。
- 新規部品が12個以上へ深く重なる配置は拒否する。停止中の同一点連打で接触グラフを膨張させないための制限。破壊痕は直近512件、爆発累計は別に保持する。
- 記録は直近約30秒。巻戻しは小さい場で約10秒、大きい場で約12秒。負荷の大きい場は時点保存1秒間隔・取り消し6段。
- 設計図JSONは配置・接続・水の分布。速度・熱の途中・過去映像を保存する形式ではない。再実験・場の切替前に必要な設計を保存する。
- 比較は1本。連続した巻戻しでは上書き前の未来を維持し、その記録区間を通過すると解放する。点線は剛体だけで、水の過去分布は重ねない。
- 弾道ガイドは通常の重力と空気抵抗の自由飛翔。衝突、磁場、重力井戸、水の力を予測しない。
